ทดสอบการส่งข้อความและรับ response กลับมา

👋 Demo 2: ระบบทักทาย Agent

จำลองการ login และทักทายเหมือนใน agent wallboard

📊 Process Information

🖥️ Main Process: ทำงานใน Node.js environment, จัดการ business logic 🎨 Renderer Process: ทำงานใน Chromium environment, แสดง UI 🌉 Preload Script: ตัวกลางที่ปลอดภัยสำหรับ IPC communication 🔄 การทำงาน: 1. Renderer เรียก window.electronAPI.sendMessage() 2. Preload ส่งต่อไป Main ด้วย ipcRenderer.invoke() 3. Main ประมวลผลด้วย ipcMain.handle() 4. Main ส่ง response กลับ 5. Renderer ได้รับผลลัพธ์
