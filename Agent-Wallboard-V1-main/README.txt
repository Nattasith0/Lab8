🏢 Agent Wallboard v1.0.1
=========================

📋 System Requirements:
- Windows 10/11 (64-bit)
- 4GB RAM
- 100MB Storage

🚀 Installation:
1. ดาวน์โหลด Agent-Wallboard-Setup-1.0.1.exe
2. คลิกขวา > Run as Administrator
3. ติดตั้งตามขั้นตอน
4. เปิดจาก Start Menu

💡 Features:
- Real-time agent monitoring
- Desktop notifications
- System tray integration
- CSV data export
- Live clock display
